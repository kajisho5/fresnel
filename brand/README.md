# fresnel brand assets

All assets are generated by `pnpm brand` (`scripts/brand.ts`). The sources are:

- `brand/AppIcon.icon`: fresnel's own app icon. It's a real Icon Composer bundle, made with fresnel from `brand/src/fresnel.spec.json`, `lens.svg` and `rings.svg`.
- `brand/src/wordmark.json`: the "fresnel" wordmark, outlined from Inter Display SemiBold (SIL Open Font License 1.1) by `brand/src/wordmark.py`.

| File | Use |
|---|---|
| `logo/fresnel-logo-dark.svg` | Horizontal lockup (icon + wordmark) for dark backgrounds |
| `logo/fresnel-logo-light.svg` | Horizontal lockup for light backgrounds |
| `logo/fresnel-wordmark-white.svg` / `-black.svg` | Wordmark only |
| `logo/fresnel-mark.svg` | App icon (vector, squircle) |
| `png/AppIcon-1024.png` | App icon, Default appearance, masked |
| `png/AppIcon-dark-1024.png` | App icon, Dark appearance, masked |
| `png/AppIcon-fullbleed-1024.png` | Unmasked, opaque square (App Store style) |
| `social/og-image.png` | Open Graph / X card (1200×630), also served at `/og-image.png` on the web app |
| `social/github-social-preview.png` | GitHub social preview (1280×640). Upload it in the repository's Settings → General → Social preview |
| `apps/web/public/favicon.svg`, `favicon.ico` | Browser tab icons (16/32/48) |
| `apps/web/public/apple-touch-icon.png` | 180×180, opaque, unmasked. iOS applies the mask |
| `apps/web/public/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | PWA icons (`site.webmanifest`) |
| `apps/desktop/src-tauri/icons/*` | Desktop app icons (`pnpm --filter @fresnel/desktop icons`) |

## Guidelines

These follow Apple's Human Interface Guidelines for app icons, and the same rules fresnel checks in your icons.

- **Don't redraw the icon.** Use the files above. The icon is a background plus two layered groups (rings and lens). Effects come from the system: no baked highlights or shadows.
- **Don't add the mask yourself** when a platform applies one (iOS home screen, `apple-touch-icon`, App Store). Use the full-bleed files there.
- **Clear space.** Around the lockup, keep at least the height of the wordmark's "f" on every side.
- **Minimum size.** 16 px for the icon. Below 24 px, use the icon without the wordmark.
- **Color.** Use the wordmark in white (`#F5F5F7`) on dark, or near-black (`#1D1D1F`) on light. Don't recolor or outline it.
- **Name.** Write "fresnel" in lowercase, in text and in the wordmark.
- Don't use Apple's product names, trademarks, or hardware imagery in fresnel's branding.
