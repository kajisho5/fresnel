# 設計書：複数選択・整列・分布（v0.2 候補）

状態：**実装済み**（2026-10-17 承認、Step 3 完了）。デザインは [`design/04-multi-select.svg`](../../design/04-multi-select.svg)。

## 1. 目的と根拠

Icon Composer の操作に合わせて、複数のレイヤーやグループをまとめて選択・編集・整列できるようにする。

| 根拠（一次情報） | 内容 |
|---|---|
| Apple「Creating your app icon using Icon Composer」 https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer | Command キーを押しながらクリックで複数選択、ドラッグの選択枠でまとめて選択、Escape で選択解除。Arrange メニューから Align / Distribute |

- 事実：上記の 3 操作と Align / Distribute があること（Apple のドキュメントに記載）。
- 推測：整列の基準（選択範囲かキャンバスか）、各メニュー項目の名前と並び、ショートカットの有無。Apple の文書では確認できないため、本設計で決める。ショートカットは独自に割り当てない（Icon Composer と食い違うのを避ける）。

## 2. 要件

### 2.1 選択
| 操作 | 場所 | 結果 |
|---|---|---|
| クリック | サイドバー・キャンバス | その 1 つだけを選ぶ（今と同じ） |
| ⌘ ＋ クリック | サイドバー・キャンバス | 選択に追加 / 外す |
| ⇧ ＋ クリック | サイドバー | 直前に選んだ行から、同じ種類の行までを範囲選択 |
| 何もない所からドラッグ | キャンバス | 選択枠。枠に**重なった**レイヤーを選ぶ（⇧ / ⌘ を押していれば今の選択に追加） |
| ⌘A | キャンバス / サイドバー | 全レイヤーを選ぶ（テキスト入力中は除く） |
| Esc | どこでも | 選択解除（今と同じ） |

- 同時に選べるのは**同じ種類だけ**（レイヤー同士、またはグループ同士）。違う種類を ⌘ ＋ クリックしたら、その項目だけの選択に切り替える。
- レイヤーは**別のグループのものも一緒に**選べる。
- 書類（最上段）は複数選択に含めない。

### 2.2 まとめて編集
- **インスペクタ**：見出しは「3 個のレイヤー」のように件数を出す。全員の値が同じなら値を、違えば「混在」（数値欄は「—」、ポップアップは「混在」）を表示する。変更すると全員に同じ値を入れる。取り消しは 1 回分。
- 「Applies to」と「Vary for…」は単一選択と同じに動き、選んだ全員に適用する。
- 画像の差し替え（Composition → Image）は複数選択では出さない。
- **キャンバス**：ドラッグと矢印キーで全員を同じだけ動かす（1 回のドラッグ＝取り消し 1 回）。中央への吸着は選択範囲全体の中心で判定する。
- **コマンド**：削除、複製、表示 / 非表示、スタイルのペーストは全員に適用する。⌘G（グループ化）は選んだレイヤーを 1 つの新しいグループにまとめる（新しいグループは、選んだ中でいちばん手前のレイヤーがあったグループの位置に入る）。前面へ / 背面へは、各項目をそれぞれ 1 段ずつ動かす。
- スタイルのコピーは、最後に選んだ項目（主選択）から取る。

### 2.3 整列・分布（Arrange）
| 項目 | 動作 |
|---|---|
| 左揃え / 左右中央 / 右揃え | 各項目の外接矩形の左端 / 中心 / 右端を、基準に合わせる |
| 上揃え / 上下中央 / 下揃え | 同じく縦方向 |
| 左右に均等配置 / 上下に均等配置 | 3 個以上のとき。両端の項目は動かさず、間の項目の中心を等間隔に並べる |

- **基準**：2 個以上なら選択範囲（全員の外接矩形）、1 個ならキャンバス（1024 pt の正方形）。インスペクタの「基準」切替で「キャンバス」を選ぶと、複数でもキャンバス基準にする。
- **置き場所**：
  - アプリメニュー → Arrange（整列）のサブメニュー
  - キャンバスとサイドバーの右クリックメニュー → 整列 ▸
  - インスペクタの Composition セクションの「整列」行（アイコンボタン 6 個＋均等配置 2 個＋基準切替）。選択が 1 個以上のとき表示する。
- 整列は位置（`position.translation-in-points`）だけを変える。拡大率は変えない。
- 「Applies to」が platform の variant のときは、その variant の位置を書き換える（単一選択の Layout と同じ）。

## 3. 状態管理（State）

```ts
// packages/ui/src/store/ui.ts
type NodeRef = { kind: 'group' | 'layer'; id: string };
type Selection =
  | { kind: 'document' }
  | NodeRef                                              // 単一（従来どおり。既存コードの互換のため残す）
  | { kind: 'multi'; of: 'group' | 'layer'; ids: string[]; primary: string }; // 複数（2 個以上）

selectedRefs(sel): NodeRef[]   // 0〜n 個に正規化するヘルパー。コマンドはすべてこれ経由で処理する
select(ref) / toggleSelect(ref) / selectRange(ref) / selectMany(refs)
```

- 複数選択が 1 個に減ったら単一の形に戻す（既存の単一前提コードがそのまま動く）。
- 削除や取り消しで存在しなくなった id は、選択から自動で外す（既存の選択ガードを拡張）。

## 4. データ処理（packages/core）

- `alignNodes(doc, refs, how, ctx, basis)`：`how` は `left | hcenter | right | top | vcenter | bottom`。
- `distributeNodes(doc, refs, axis, ctx)`：`axis` は `horizontal | vertical`。
- 外接矩形は既存の `layout()`（`packages/ui/src/lib/geometry.ts`）をコアへ移して共有し、キャンバス座標で計算する。動かす量はレイヤーが属するグループの拡大率で割って、各レイヤーの座標系に戻す。
- 1 回の整列は 1 回の `mutate`（＝取り消し 1 回）。MCP にも同じ操作を `icon_align` として公開する（引数：path、targets[]、how、basis）。

## 6. 見た目（HIG A2・A4 準拠）

- 選択中の各項目：1px の accent 枠（今の選択枠と同じ）。複数のときは、全体の外接矩形を 1px の accent 破線で囲み、四隅にハンドル（表示のみ）。
- 選択枠（マーキー）：accent の 1px 枠＋ accent 10% の塗り。
- サイドバー：選択行は今と同じ `--bg-selected`。主選択（最後に選んだ行）の文字は太字にしない（Icon Composer と同じく区別しない）。
- 整列ボタン：24×22 のアイコンボタン。キーボードで操作でき、`aria-label` に「左揃え」などの名前を付ける。均等配置は 3 個未満なら無効表示。

## 7. エッジケース

- 非表示の項目も選べ、整列の対象になる（外接矩形は計算できるため）。
- 画像が見つからないレイヤー（V-02）は外接矩形がないので、整列・分布の対象から外す。
- グループとレイヤーをまたいだ選択はしない（2.1）。
- 選択枠のドラッグは、ドラッグ開始時に項目の上なら移動、何もない所なら選択枠として扱う。
- 1 個だけのときの「均等配置」は無効。2 個のときも無効（Icon Composer の挙動は不明。一般的なデザインツールに合わせる）。

## 8. テスト

- core：整列 6 種と分布 2 種（グループの拡大率あり / なし、variant あり）、選択の正規化。
- E2E：⌘ ＋ クリックで 2 個選ぶ → インスペクタに「2 個のレイヤー」と混在表示 → 左揃え → X が揃う → 1 回の取り消しで戻る。選択枠でまとめて選ぶ。⌘G でまとめてグループ化。
