# fresnel Human Interface Guidelines

fresnel 自身の UI を作るときのルールブック。実装・レビュー・コントリビュートの判断基準はすべてここに置く。

- **Part A**：fresnel アプリの UI ガイドライン（デザイントークン、レイアウト、コンポーネント、操作、文言、アクセシビリティ）
- **Part B**：fresnel で作るアイコンの制作ガイド（Apple HIG の要約。アプリ内のヒントや検証ルールの根拠）

> 基本姿勢：**macOS ネイティブアプリに見えること**を最優先する。そのうえで Windows / Linux / Web でも違和感がない中立的な作りにする。Apple の HIG（macOS）の考え方に従うが、Apple の素材（SF Symbols、SF フォントの同梱、Apple のアイコン）は使わない。

# Part A — アプリ UI

## A1. 原則

1. **作品が主役。** UI はグレーで静かにする。色を使ってよいのはアクセント（選択、フォーカス、主ボタン）と状態色だけ。キャンバス上のアイコンより目立つ UI を置かない。
2. **見たまま即反映。** パラメータの変更は 16ms 以内にプレビューへ反映する。「適用」ボタンは置かない。
3. **どの外観を編集しているか常にわかる。** 現在の外観と上書きのスコープを、ツールバー・キャンバス・インスペクタの 3 か所で一貫して表示する。
4. **壊さない。** すべての操作は Undo できる。破壊的な操作（削除、上書き保存、書き出し先の上書き）だけに確認を出す。
5. **近似であると正直に示す。** プレビューは Apple の描画と同一ではない。「Approximate preview」の表示を隠さない。

## A2. デザイントークン

すべての色・寸法は CSS 変数（`packages/ui/tokens.css`）から使う。値の直書きは禁止。

### A2.3 ブランド・スペクトル

`--spectrum: linear-gradient(90deg, #5B8CFF 0%, #9B6BFF 50%, #FF7AB6 100%)`
**使ってよいのは**アプリアイコン、ウェルカム画面のロゴ、書き出し完了の演出だけ。作業 UI では使わない（原則 1）。

### A2.4 タイポグラフィ

| ロール | サイズ / 行高 / ウェイト | 用途 |
|---|---|---|
| `title` | 20 / 26 / 600 | シートのタイトル |
| `headline` | 13 / 18 / 600 | インスペクタのセクション見出し |
| `body` | 13 / 18 / 400 | 既定（macOS の標準本文サイズに合わせる） |
| `callout` | 12 / 16 / 400 | ラベル、ツリーの行 |
| `caption` | 11 / 14 / 400 | 補足、ステータスバー |
| `mono` | 12 / 16 / 400 tabular | 数値入力、座標、色の値 |

- フォントスタック：`-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans JP", system-ui, sans-serif`。等幅は `ui-monospace, "SF Mono", "Cascadia Mono", monospace`
- 数値はすべて `font-variant-numeric: tabular-nums`
- フォントは同梱しない（OS 標準を使う）

### A2.5 スペーシング・角丸・寸法

- 4px グリッド：`4 / 8 / 12 / 16 / 20 / 24 / 32`
- 角丸：コントロール 6、パネル内カード 8、ポップオーバー 10、シート 14、比較タイル 12
- 寸法

| 要素 | 値 |
|---|---|
| ツールバーの高さ | 52 |
| ステータスバーの高さ | 24 |
| サイドバーの幅 | 260（220〜360 で可変） |
| インスペクタの幅 | 300（固定） |
| ツリーの行 | 28（インデント 16） |
| コントロールの高さ | 24（regular）/ 20（small） |
| 最小ヒット領域 | 24×24（デスクトップ）/ 44×44（Web のタッチ） |
| ウィンドウ | 既定 1440×900、最小 1024×680 |

### A2.6 エレベーションとマテリアル

- ポップオーバー / シート：`--bg-elevated` ＋ 1px 枠 `rgba(255,255,255,0.08)` ＋ 影 `0 12px 40px rgba(0,0,0,0.45)`
- キャンバス上の HUD：`rgba(44,44,47,0.72)` ＋ `backdrop-filter: blur(20px)`（効かない環境では不透明の `--bg-elevated`）
- それ以外の面はフラット（影なし）

### A2.7 モーション

| 種類 | 時間 / イージング |
|---|---|
| ホバーの色変化 | 80ms linear |
| パネルの開閉 | 200ms `cubic-bezier(0.2, 0, 0, 1)` |
| シートの表示 | 240ms 同上（上から 8px スライド＋フェード） |
| 外観の切替（プレビュー） | 180ms クロスフェード |

`prefers-reduced-motion` のときは、すべてフェードだけにして 0〜80ms に短縮する。

## A3. レイアウト

- **Icon Composer に準じた 3 ペイン構成**：サイドバー（ドキュメント → グループ → レイヤー）→ キャンバス → インスペクタ。左から右へ「選ぶ → 見る → 変える」の流れ。
- キャンバスの上端にキャンバス用ツールバー（背景・グリッド・プレビューサイズ・ズーム・Effects）、下端にプラットフォームと外観の切替を置く。
- ウィンドウ幅が 1180 未満になったら、インスペクタをオーバーレイに切り替える。1024 未満ではサイドバーも折りたたむ。

## A4. コンポーネント規約

### Toolbar（ウィンドウ上端）
- 左：アプリメニュー（テーマ・言語・並べ替えなど）→ ドキュメント名（未保存なら「— Edited」をグレーで表示）→ 取り消し / やり直し
- 右：`Compare` → `Export…`（主ボタン。accent 色を使うのはこれだけ）→ Style / Document インスペクタの切替
- Windows / Linux ではタイトルバーと統合し、ウィンドウボタンは右端に置く

### Sidebar
- 先頭行はドキュメント（ファイル名＋アイコンのサムネイル）。選択するとインスペクタは Document 表示になる
- 表示順は **前面が上**（Icon Composer と同じ。保存時の順序はモデル側で変換する）
- 行の構成：開閉 ▸ / サムネイル / 名前 / 右端に表示トグル（ホバー時と非表示時だけ見せる）
- 「＋」メニュー：New Image… / New Group。右クリックでコンテキストメニュー（複製・削除・グループ化・並べ替え・スタイルのコピー / ペーストなど）
- ダブルクリックで名前を変更する
- フォルダをドロップするとグループになる。グループは 4 個まで（超えると検証エラー V-09）
- D&D：挿入位置を 2px の accent 線で示す

### Canvas
- 上部ツールバー：背景（色 / 壁紙画像 / 任意の画像）、グリッド（Light / Dark）、プレビューサイズ、ズーム、Effects のオン / オフ
- 下部：プラットフォーム（iOS / macOS / watchOS。Document の supported-platforms にあるものだけ）と外観（Default / Dark / Mono）のセグメント。Mono の「Options」ポップオーバーで Light / Dark・Tinted・色相と強さを選ぶ
- 選択中のレイヤーは枠で示し、ドラッグで移動する（中央でスナップ）。矢印キーで 1pt、⇧ で 10pt 動かす
- 小さいプレビューサイズでは、ピクセルを補間せずに拡大して表示する
- watchOS では円形マスクで表示する
- D&D 中はキャンバス全体を 2px の破線 accent 枠でドロップゾーンにする

### Inspector
- タブ：`Style | Document`
- Style には `Color` / `Liquid Glass` / `Composition` の 3 セクションを置く。各セクションの見出しにある「Applies to」ポップアップで、編集先を All（基本値）か、いま表示中の外観・プラットフォームに切り替える
- 上書きした値は、基本値の下にバリアント行として並べる（行末の − で削除）。各設定の「＋」から「Vary for…」で外観やプラットフォームごとのバリアントを追加する
- Liquid Glass：Mode（Individual / Combined）、Specular（Off / Automatic / Inside / Outside）、Blur、Translucency、Shadow、Refraction（2D パッド）
- 数値フィールドは式も受け付ける（`*2`、`35*3` など）。↑↓ で ±1、⇧ で ±10
- Document：対象プラットフォーム（iOS・macOS の組み合わせ、watchOS のトグル）とカラースペース

### コントロール
| 種類 | 規約 |
|---|---|
| Slider | トラック 4px、塗りは accent、ノブ 14px の白丸＋影。ダブルクリックで既定値に戻る |
| Toggle | 26×16 のスイッチ。ON は accent |
| Segmented | 高さ 24、選択中は `--bg-elevated` ＋薄い影（macOS 風） |
| ColorWell | 22×22 の角丸 4 スウォッチ＋値（`display-p3:…` を mono で）。クリックでポップオーバー（Display P3 / sRGB 切替、HEX 入力） |
| Select | ネイティブ風のポップアップボタン。blend-mode のような長いリストは区切り線でグループ化 |
| Button | 主（accent 塗り）/ 副（`--bg-control`）/ 危険（error 色の文字）。高さ 28（シート内）/ 24（パネル内） |

### Sheet / Popover
- シートはウィンドウ上端から表示し、幅は 560 固定。主ボタンは右下、キャンセルはその左。Esc でキャンセル、⏎ で主ボタン
- 破壊的な確認は、主ボタンを error 色にして既定ボタンにしない

## A5. 文言（UI コピー）

- 英語：Title Case はメニューとボタンだけ。ラベルは Sentence case。末尾にピリオドを付けない
- 日本語：です・ます調は使わず、体言止めの短いラベルにする。「〜する」ボタンは動詞で終える（例：「書き出す」）
- Apple の用語は、Apple が公開している呼び方に合わせる（Default / Dark / Clear / Tinted、Specular、Translucency）
- 「Liquid Glass」「Icon Composer」は説明文中の参照に限って使う。機能名・ボタン名・アプリ名には使わない
- エラーは「何が起きたか＋どうすればよいか」の 2 文で書く。例：`Layer "Sun" isn't square. Export a 1024×1024 canvas from your design tool.`

## A6. アクセシビリティ

- すべてのコントロールに accessible name を付ける（Radix ＋ `aria-label`）。プレビューには `aria-live` で「Dark appearance」などの現在状態を伝える
- フォーカスリング：2px accent ＋ 2px オフセット。マウス操作では非表示（`:focus-visible`）
- Tab 移動の順序：ツールバー → サイドバー → キャンバス HUD → インスペクタ → ステータスバー。F6 でペイン間を移動
- ツリーは WAI-ARIA の `tree` パターン（矢印キーで移動、Space で表示切替、Enter で名前の変更）
- 色だけで情報を伝えない（上書きマーカーはドット＋ツールチップ。検証結果はアイコン形状でも区別する）
- 文字サイズ：OS 側の設定に追従し、UI を 0.85〜1.3 倍で拡縮できるようにする（環境設定）

## A7. プラットフォーム差分

| 項目 | macOS | Windows | Linux | Web |
|---|---|---|---|---|
| メニュー | ネイティブのメニューバー | ウィンドウ内のメニュー（≡） | 同左 | ≡ メニュー |
| 修飾キー | ⌘ | Ctrl | Ctrl | OS に従う |
| ファイル | `.icon` ディレクトリ | 同左 | 同左 | `.icon.zip` |
| actool | 利用可（Xcode 26 以降がある場合） | 非表示 | 非表示 | 非表示 |
| ウィンドウ背景 | vibrancy なし（一貫性を優先） | Mica なし | — | — |

# Part B — アイコン制作ガイド（アプリ内ヒントの根拠）

出典：Apple Human Interface Guidelines “App icons”（2026-06-08 改訂）
https://developer.apple.com/design/human-interface-guidelines/app-icons
以下は要約。最新の内容は必ず原文で確認すること。

## B1. 仕様

| プラットフォーム | レイアウト | マスク後 | サイズ | 外観 |
|---|---|---|---|---|
| iOS / iPadOS / macOS | 正方形 | 角丸矩形 | 1024×1024 | Default, Dark, Clear light, Clear dark, Tinted light, Tinted dark |
| watchOS | 正方形 | 円 | 1088×1088 | — |
| visionOS | 正方形 | 円（3D） | 1024×1024 | — |
| tvOS | 横長矩形 | 角丸矩形 | 800×480 | —（パララックス） |

色空間：sRGB / Gray Gamma 2.2 / Display P3

## B2. 制作ルール → fresnel での扱い

| Apple の推奨 | fresnel の対応 |
|---|---|
| 背景＋1 枚以上の前景で構成する | 新規ドキュメントのテンプレートを「Background ＋ Group 1」にする |
| レイヤーはマスクせず正方形で渡す | 検証 V-03 / V-04 |
| 前景のエッジはくっきりさせる（ぼかし・フェザーを避ける） | 取り込み時に半透明エッジの比率が高い場合はヒントを出す |
| 不透明で取り込み、透明度はツール側で調整する | opacity スライダーを最上位に置く |
| 背景は単色またはグラデーション。画像の場合は full-bleed かつ不透明 | Fill を既定にする。検証 V-05 |
| ベクター（SVG / PDF）を優先し、テキストはアウトライン化する。ラスターは PNG | 取り込みダイアログの形式ヒント。検証 V-07 |
| シンプルに、少ない形で | 4 グループを超えたら警告 |
| ハイライト、影、ベベル、ブラーを焼き込まない（システムが付ける） | 取り込み時にフィルタ要素（`<filter>`）を検出したらヒントを出す |
| エフェクトはグループ単位でまとめて適用できる | Group インスペクタに Liquid Glass の設定を集約する |
| 外観間でモチーフを入れ替えない | 上書きできるのは色・不透明度・表示だけ。画像の差し替えは警告付き |
| Dark は Default をもとに作り、明るすぎる画像を避ける | Compare ビューで Default と Dark を並べて表示する |
| 主要な要素は中央に置く（マスクで切れないように） | グリッドのセーフエリアを表示。円マスクのプレビュー |
| 極細線や鋭角を避ける | 検証 V-06 ＋ Compare の 16px タイル |

## B3. fresnel が保証しないこと

- 実機の描画と同一の見た目（近似プレビュー）
- Apple の審査への適合（App Review Guidelines は別途確認すること）
- `.icon` 形式の将来の互換性（Apple が非公開・予告なしに変更する可能性がある）
