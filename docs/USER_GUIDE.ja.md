## 1. 基本の考え方

Liquid Glass 用のアプリアイコンは、1 枚の絵ではなく「重ね」で作ります。

| 要素 | 内容 |
|---|---|
| **背景** | いちばん後ろの塗り。単色、グラデーション、システムの塗りから選ぶ |
| **グループ** | Liquid Glass の設定（透過、ぼかし、ハイライト、影、屈折）を共有するレイヤーのまとまり。Apple の推奨は 4 個まで。リストの上にあるものほど手前 |
| **レイヤー** | 1 枚の画像（SVG／PNG／JPEG）。塗り、描画モード、不透明度、位置をそれぞれ持つ |
| **外観** | システムの Default／Dark／Clear／Tinted での見え方 |
| **プラットフォーム** | iOS／iPadOS と macOS は角丸の四角、watchOS は円 |
| **バリアント** | 特定の外観やプラットフォームだけに効く値（例：Dark のときだけ背景を暗くする） |

ガラスの効果と形のマスクは、アイコンを表示するときにシステムがかけます。fresnel はその見た目に近いプレビューを出します。

## 2. ウィンドウの構成

![fresnel のウィンドウ](images/editor.png)

| 場所 | 内容 |
|---|---|
| **ツールバー**（上） | メニュー、サイドバーの開閉、書類名（未保存なら「— Edited」）、取り消し／やり直し、**Export…**、Style／Document インスペクタの切替 |
| **サイドバー**（左） | 書類、その下にグループとレイヤー（手前が上）。下の **＋** で画像やグループを追加。横にグループ数とレイヤー数 |
| **キャンバスツールバー**（キャンバスの上） | 背景色・壁紙・画像、グリッド、プレビューサイズ、ズーム、**Effects**、**Compare** |
| **キャンバス**（中央） | ライブプレビュー。クリックで選択、ドラッグで移動 |
| **キャンバスバー**（キャンバスの下） | プラットフォーム（共通アイコンなら **iOS, macOS** の 1 つ、別々ならそれぞれ。加えて watchOS）、外観（Default／Dark／Mono）、Mono の **Options** |
| **インスペクタ**（右） | **Style**：選択中の項目の設定。**Document**：対象プラットフォームとカラースペース |
| **ステータスバー**（最下部） | キャンバスのサイズ、カラースペース、プラットフォーム、問題の件数、`actool` が使えるかどうか |

## 3. アイコンを作る手順

1. **新規作成**：**メニュー → New icon**（⌘N）。見本から始めるなら **メニュー → Try the sample**。
2. **背景**：サイドバー最上段の書類を選び、**Color → Fill** で Solid（単色）、Gradient、Auto gradient、System light、System dark、Automatic から選ぶ。
3. **レイヤーを追加**：ファイルをウィンドウにドロップするか、**＋ → New Image…**（⇧⌘I）。複数のファイルは名前順に並べ、名前が後ろのものほど手前に置きます。`1-back.svg`、`2-middle.svg`、`3-front.svg` と名付ければ、その順で重なります。
4. **グループにまとめる**：フォルダをドロップすると、フォルダ名のグループになります。レイヤーを選んで ⌘G を押すと、そのレイヤーを新しいグループで包みます。**＋ → New Group** でも作れます。
5. **グループの設定**：グループを選んで **Liquid Glass** を設定します。まず透過とぼかし、次にハイライトと影。
6. **レイヤーの設定**：レイヤーを選んで **Color**（塗り、描画モード、不透明度）を設定します。ハイライトを受けるレイヤーは **Liquid Glass → Effects** をオンにします。
7. **位置合わせ**：キャンバス上でドラッグするか、矢印キーで動かすか、**Composition → Layout** に X、Y、拡大率を入力します。
8. **Dark と Mono**：⌥2 で Dark、⌥3 で Mono に切り替え、見えにくいところを[バリアント](#8-バリアントvary-for)で調整します。
9. **確認**：⌘2 ですべての外観とサイズを比較します。ステータスバーの件数をクリックすると、チェックの結果が見られます。
10. **保存と書き出し**：⌘S で `.icon` を保存、⇧⌘E で Xcode、App Store、macOS、Web 向けに書き出します。

## 4. サイドバー

- **選択**：行をクリック。↑↓ で上下に移動、←→ でグループを折りたたむ／開く。
- **並べ替え**：行をドラッグします。線が入る位置を示します。行の上半分に落とすとその前、下半分なら後ろに入ります。レイヤーをグループの行に落とすと、そのグループの先頭に入ります。⌘]（前面へ）と ⌘[（背面へ）でも動かせます。
- **名前の変更**：名前をダブルクリックし、入力して Return。Esc で取り消し。
- **表示／非表示**：行にポインタを合わせて目のアイコンをクリック、または ⇧⌘H。非表示の項目は薄く表示されます。表示状態もバリアントにでき、たとえば watchOS だけ非表示にできます。
- **コンテキストメニュー**：右クリックで、複製（⌘D）、前面へ／背面へ、グループ化／解除、表示／非表示、スタイルのコピー／ペースト、削除。
- **バッジ**：**Glass** は、透過がオンのグループ、またはガラス効果のレイヤーを含むグループに付きます。
- **スタイルのコピー／ペースト**（⌥⌘C／⌥⌘V）：画像と名前以外のすべての設定を、同じ種類（グループ同士、レイヤー同士）の別の項目に写します。

## 5. キャンバス

### 選択と移動

- 絵をクリックすると、ポインタの下にあるレイヤーを選びます。何もないところをクリックすると選択を解除します（Esc でも解除）。
- 選択中のレイヤーやグループはドラッグで動かせます。中心はキャンバスの中心線に吸着します。⇧ を押しながらドラッグすると、縦または横だけに動きます。
- 矢印キーで 1pt、⇧ ＋ 矢印キーで 10pt 動きます。
- 1 回のドラッグは、取り消し 1 回分です。

### キャンバスツールバー

| 項目 | 内容 |
|---|---|
| 色の四角 | キャンバスの背景色 |
| 壁紙メニュー | なし、Gradient、Sunset、Ocean、Night、**Add Background…**（自分の画像）。横のボタンで画像の表示を切り替え |
| グリッド | Apple のテンプレートに準じたガイド線。明るい色と暗い色を選べる |
| プレビューサイズ | **Fit**、または 1024／512／256／128／64／32／16 px。小さいサイズはピクセル単位で表示し、実際の見え方を確かめられる |
| ズーム | 25〜200%（⌘＋／⌘−／⌘0） |
| **Effects** | オフにすると、Liquid Glass の効果（影、透過、ハイライト、縁）を外した状態で見られる |
| **Compare** | [比較](#9-比較compare)を開く（⌘2） |

「Approximate preview（近似プレビュー）」の表示は、Apple のレンダラーが非公開であることを示しています。プレビューは近い見た目ですが、最終的な描画はシステムが行います。

## 6. インスペクタ

### Style

選択中の項目の設定が 3 つのセクションに並びます。各セクションの見出しにある **Applies to** ポップアップで、編集先を切り替えます。**All** は基本値を編集し、**Dark**／**Mono**／**watchOS** などは、いま表示している外観やプラットフォームだけを編集します。詳しくは[バリアント](#8-バリアントvary-for)を参照してください。

**Color**

| 設定 | 対象 | 内容 |
|---|---|---|
| Fill（塗り） | 書類、レイヤー | Automatic、None、Solid、Gradient（From／To。⇅ で入れ替え）。書類ではさらに Auto gradient、System light、System dark も選べる。色ごとに HEX 値と不透明度を設定する。Display P3 の色は P3 のまま保たれる |
| Blend mode（描画モード） | グループ、レイヤー | Normal、Multiply、Screen、Overlay など標準のモードに加え、Plus Darker と Plus Lighter |
| Opacity（不透明度） | グループ、レイヤー | 0〜100% |

**Liquid Glass**

| 設定 | 対象 | 内容 |
|---|---|---|
| Mode | グループ | **Combined** はグループ全体を 1 枚のガラスとして光らせる。**Individual** はレイヤーごとに光らせる |
| Specular | グループ | Off／Automatic／Inside／Outside。縁のどこにハイライトを付けるか |
| Blur | グループ | すりガラスの強さ |
| Refraction | グループ | オンにしてパッドをドラッグ。横が強さ、縦が深さ |
| Translucency | グループ | 背景の透け具合 |
| Shadow | グループ | None／Neutral／Chromatic と、その不透明度 |
| Effects | レイヤー | そのレイヤーがガラスのハイライトを受けるかどうか |

**Composition**

| 設定 | 対象 | 内容 |
|---|---|---|
| Visible | グループ、レイヤー | サイドバーの目のアイコンと同じ |
| Image | レイヤー | アイコン内の別の画像に差し替える。**Replace…** で新しいファイルに差し替え |
| Layout | グループ、レイヤー | 中心からの X／Y（pt、y は下向きが正）と拡大率。0、0、100% で中央に元の大きさのまま置かれる |

### Document

| 設定 | 内容 |
|---|---|
| iOS, macOS | iOS & macOS（共通）、iOS Only、macOS Only、Off。キャンバス下に出るプラットフォームが変わる |
| watchOS | 円形の watchOS アイコンも作るかどうか |
| SVG color space | カラープロファイルのない SVG の色の解釈。Display P3（Icon Composer の既定）または sRGB |

### 数値フィールド

- 値を入力して Return または Tab で確定。Esc で取り消し。空のまま離れると元の値に戻ります。
- ↑↓ で 1 ステップ増減（⇧ で 10 倍、⌥ で 0.1 倍）。
- 計算式も使えます。`*2` で 2 倍、`+10` で 10 足す、`35*3` なら 105 になります。
- % の項目は `45` でも `45%` でも入力できます。
- スライダーをダブルクリックすると既定値に戻ります。

## 7. 外観とプラットフォーム

### 外観

| ボタン | 表示 | ショートカット |
|---|---|---|
| **Default** | 通常の明るいアイコン | ⌥1 |
| **Dark** | ダークモードのアイコン | ⌥2 |
| **Mono** | Clear または Tinted。**Options** で Light／Dark、Tinted のオン／オフ、色合い（Hue）と強さ（Intensity）を選ぶ | ⌥3 |

Dark と Mono を調整しなければ、システムが Default から自動で作ります。fresnel はその近似を表示し、チェック V-08 で知らせます。

### プラットフォーム

**iOS** と **macOS** は角丸の四角を共有します。**watchOS** は円形のマスクで表示され、外観の切り替えはありません。円で絵が欠けないよう、プラットフォームのバリアントで拡大率を小さくするなどして調整してください。

## 8. バリアント（Vary for…）

バリアントは、1 つの設定を特定の外観やプラットフォームだけ上書きするものです。Icon Composer と同じく、`icon.json` には specialization として保存されます。

**作り方は 2 通りあります。**

1. **セクション全体で**：キャンバスを編集したい状態（例：Dark）に切り替え、セクションの **Applies to** を **All** から **Dark** に変えます。見出しの下に「Edits apply to Dark only」と出ている間は、そのセクションでの変更がすべて Dark のバリアントに入ります。
2. **1 つの設定だけ**：**All** のまま設定にポインタを合わせ、ラベル横の **＋** から **Vary for Dark**（または Mono、表示中のプラットフォーム）を選びます。いまの値がコピーされた新しいバリアントができます。

**見方**：**All** のときは、基本値の下にバリアントが名前付き（Dark、Mono、iOS、macOS、watchOS や、その組み合わせ）で並びます。いまキャンバスに効いているものは強調表示されます。**×** で削除すると基本値に戻ります。

**優先順位**：外観＋プラットフォーム → 外観 → プラットフォーム → 基本値の順に、いちばん具体的なものが使われます。Mono での編集は Icon Composer と同じく tinted のキーに保存され、Clear と Tinted の両方に効きます。

**既定値に戻すとき**：バリアントで Normal、Visible、Layout の 0・0・100% のような既定値を選ぶと、その値がバリアントにそのまま保存されます。基本値が透けて出ることはありません。

## 9. 比較（Compare）

![比較](images/compare.png)

⌘2（またはキャンバスツールバーの **Compare**）で、Default、Dark、Mono · Clear light、Mono · Clear dark、Mono · Tinted light、Mono · Tinted dark を並べて表示します。表示するサイズ（1024／128／64／32／16）を選べます。**Not customized (V-08)** のバッジは、システムが自動で作る外観を示します。⌘1 で編集に戻ります。

## 10. チェック

ステータスバーに問題の件数が出ます。クリックすると一覧が開き、書き出し画面にも表示されます。エラーがあっても編集や保存はできますが、Xcode や App Store で弾かれることがあります。描画できないレイヤーが表示されている間は、画像の書き出しを止めます（気づかないまま抜け落ちるのを防ぐため）。

| ID | 重要度 | 対処 |
|---|---|---|
| V-01 | エラー | `icon.json` の値が不正。手で編集したファイルや壊れたファイルで起きやすいので、その設定をやり直す |
| V-02 | エラー | レイヤーの画像が `Assets/` にない。**Composition → Image → Replace…** で差し替える |
| V-03 | 警告 | 正方形でない、または 1024px 未満。素材を 1024×1024 で書き出し直す |
| V-04 | 警告 | 角丸が焼き込まれているように見える。素材から角丸を外す |
| V-05 | 警告 | 背景が不透明でない。App Store のアイコンは透明にできないので、不透明な塗りにする |
| V-06 | 情報 | 線がとても細い。16〜32px でも消えないよう、数 pt 以上の太さにする |
| V-07 | 情報 | SVG に文字やフィルタがある。文字はアウトライン化し、効果は外す（効果はシステムがかける） |
| V-08 | 警告 | Dark や Tinted を調整していない。比較で問題なく見えればそのままでよい |
| V-09 | 警告 | 表示中のグループが 4 個を超えている。Apple の推奨は 4 個までで、Xcode の actool のバージョンによっては受け付けない。グループをまとめる |
| V-10 | エラー | 対応していない画像形式。SVG、PNG、JPEG を使う |

## 11. 開く・保存・自動保存

### 開く

| 環境 | 方法 |
|---|---|
| Web（Chrome／Edge） | **メニュー → Open…**（⌘O）で `.icon` フォルダを選ぶ。保存するとそのフォルダに書き戻す |
| Web（Safari／Firefox） | `.icon.zip` を開くかドロップする。保存すると新しい zip をダウンロードする |
| 共通 | `.icon` フォルダか `.icon.zip` をウィンドウにドロップする |
| デスクトップ | **Open…** で `.icon` を選ぶ。macOS では `.icon` が 1 つのファイルに見える。フォルダとして見える場合は、フォルダとして開く案内が出る |

### 保存

- **Save**（⌘S）は開いた場所に保存します。Safari／Firefox や、Web で新規作成したアイコンは `名前.icon.zip` をダウンロードします。
- **Save As…**（⇧⌘S）は保存先を選び直します。Web でフォルダから開いたアイコンは、選んだ場所に新しい `名前.icon` フォルダを作って保存します。
- 入力中のフィールドの値は、保存の前に確定されます。
- 名前の横の「— Edited」は未保存の変更があるしるしです。保存した状態まで取り消すと消えます。
- 保存時、どのレイヤーも使っていない画像を `Assets/` から削除します。バンドル内のほかのファイルには触れません。

### 自動保存と復元

未保存の変更がある間、fresnel はブラウザ（IndexedDB）またはアプリの保存領域に復元用のコピーを残します。編集が止まってから約 1.5 秒後に、編集を続けている間も少なくとも 30 秒ごとに更新します。保存する前にタブやアプリが閉じた場合、次に起動したとき **Restore unsaved changes?** と聞かれます。**Restore** で作業が戻り（未保存の扱いのまま）、**Discard** でコピーを削除します。コピーが端末の外に出ることはありません。

### ファイルがディスク上で変わったとき（デスクトップ）

MCP 経由の AI エージェントなど、ほかのプログラムが開いている `.icon` を変更すると、デスクトップアプリは自動で読み込み直します。未保存の変更がある場合は読み込み直さずに通知するので、自分の内容で保存するか、開き直すかを選べます。

## 12. 書き出し

![書き出し](images/export.png)

⇧⌘E か **Export…** で開きます。形式は複数選べます。

| 形式 | 中身 | 用途 |
|---|---|---|
| **.icon bundle** | `名前.icon/` | Xcode 26 以降。プロジェクトにドラッグし、アプリアイコンとして選ぶ |
| **macOS .icns** | `名前.icns`（16〜1024px、@1x と @2x。従来の macOS テンプレートの形で、macOS 用のバリアントを使う） | アセットカタログを使わない Mac アプリ、インストーラ、DMG |
| **AppIcon.appiconset** | `Contents.json` と PNG | Xcode のアセットカタログ全般。iOS の 1024px 画像は App Store の要件どおり、アルファのない不透明な RGB。Dark は Apple の指示どおり背景が透明、Tinted はグレースケール。macOS の各サイズは従来の macOS テンプレート（周囲に余白と影）で、macOS 用のバリアントを使う。watchOS 対象なら watchOS 用の画像も入る |
| **PNG set** | `名前-png/<外観>/icon-<サイズ>.png` | Web サイト、ストアページ、資料。全外観か Default のみを選べる |
| **Assets.car** | Apple の `actool` でコンパイル | macOS で Xcode 26 以降を入れたデスクトップアプリのみ |

書き出し画面にはチェックの結果も表示されます。Web では `名前-export.zip` としてまとめてダウンロードし、デスクトップでは保存先のフォルダを聞きます。Return で実行、Esc で閉じます。

プレビュー、`.icns`、PNG、appiconset は fresnel によるガラスの近似で描かれます。`.icon` はレイヤー構造のまま保存され、実機ではシステムが描画します。

## 13. 環境設定

**メニュー**から：

- **Theme**：Dark → Light → System の順に切り替わります。
- **Language**：English／日本語。

次の設定は、このブラウザで次回以降も保持されます。

## 14. キーボードショートカット

Windows と Linux では ⌘ の代わりに Ctrl を使います。

| | |
|---|---|
| **ファイル** | 新規 ⌘N・開く ⌘O・保存 ⌘S・別名で保存 ⇧⌘S・書き出し ⇧⌘E |
| **編集** | 取り消し ⌘Z・やり直し ⇧⌘Z・複製 ⌘D・削除 ⌫・スタイルをコピー ⌥⌘C・スタイルをペースト ⌥⌘V |
| **レイヤー** | 画像を追加 ⇧⌘I・グループ化 ⌘G・解除 ⇧⌘G・前面へ ⌘]・背面へ ⌘[・表示／非表示 ⇧⌘H |

## 15. 素材の作り方

Apple の [Human Interface Guidelines「App icons」](https://developer.apple.com/design/human-interface-guidelines/app-icons)に基づくルールです。

- **1024×1024 の正方形で、マスクしない**：角丸は描かないでください。マスクはシステムがかけます。角丸を焼き込むと縁がギザギザになり、ハイライトも崩れます。
- **レイヤーの背景は透明に**：背景は書類の Fill に設定し、レイヤーには入れません。
- **アイデアは 1 つ、形は少なく**：塗りのある単純な形を重ね、細い線や細部は避けます。
- **素材は不透明に**：透明度は fresnel 側（不透明度、透過）で設定します。レイヤーごとに不透明度を変えると奥行きが出ます。
- **効果を焼き込まない**：ドロップシャドウ、ベベル、グロー、ハイライトは入れません。システムが描きます。
- **ベクターを優先**：SVG で、文字はアウトライン化します。PNG は写実的な絵やメッシュグラデーションに使います。
- **中身は中央に**：watchOS の円で欠けないようにします。
- **どの外観でも同じアイコンに**：Dark や Mono でも要素は変えず、色だけを調整します。

## 16. AI エージェントと使う（MCP）

fresnel の MCP サーバーを使うと、Claude などのエージェントがアイコンを作り、結果を画像で見せてくれます。設定方法は [README](../README.md#mcp-server) を参照してください。頼み方の例：

- 「~/Icons に Habit.icon を作って。背景はティールのグラデーション、チェックマークをガラスで。全外観を見せて」
- 「ダークの背景をもっと暗くして、ダークのときだけ透過を 30% に」
- 「Habit.icon をチェックして、直せるところは直して」
- 「Habit.icon を appiconset と PNG で ~/Icons/out に書き出して」

エージェントが触れるのは `--root` で許可したフォルダの中だけです。デスクトップアプリで開いているアイコンをエージェントが変更すると、アプリが読み込み直します。

## 17. コマンドライン

コマンドの一覧は [README](../README.md#command-line) にあります。よくある使い方：

```bash
# CI：エラー（--strict なら警告も）があればビルドを失敗させる
fresnel validate App/AppIcon.icon --strict

# ストアや Web 用の画像を作る
fresnel export App/AppIcon.icon -o build/icons --formats png --sizes 1024,512,180 --appearances default,dark

# プルリクエスト用の一覧画像
fresnel render App/AppIcon.icon --sheet -o icon-sheet.png
```

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| **Open…** で zip しか選べない | Safari と Firefox はフォルダを開けません。`.icon` フォルダを zip にするか、Chrome、Edge、デスクトップアプリを使ってください |
| 保存するたびに zip がダウンロードされる | フォルダに書き込めない環境では、保存はダウンロードになります。Chrome か Edge で **Open…** から `.icon` フォルダを開けば、以降はそのフォルダに書き戻します |
| レイヤーが小さすぎる／大きすぎる | レイヤーは 1024pt のキャンバスに元のピクセルサイズで置かれます。アートボードを 1024×1024 にするか、**Layout** の拡大率を変えてください |
| レイヤーが中央からずれる | 素材がアートボードの中央にありません。作画アプリで中央に置き直すか、X／Y で調整してください |
| 角が二重やギザギザに見える | 素材に角丸が焼き込まれています（V-04） |
| 作画アプリと色が違う | **Document → SVG color space** を確認してください。Icon Composer はプロファイルのない SVG の色を Display P3 として読みます |
| V-09「More than 4 groups」が出る | Apple の推奨は 4 個までで、actool のバージョンによっては 5 個以上を受け付けません。グループをまとめてください |
| Dark でだけ変わる／Dark でだけ変わらない | セクションの **Applies to** と、設定の下にあるバリアントの行を確認してください |
| 目のアイコンが効かないように見える | 表示状態に、この外観かプラットフォームのバリアントがある可能性があります。**All** にして **Composition → Visible** を確認してください |
| 取り消しボタンが押せない | 開いてから取り消せる操作がまだありません |
| Safari で書き出した画像が空白 | もう一度試すか別のブラウザを使い、ぜひ報告してください |
| **Assets.car** が選べない | macOS で Xcode 26 以降を入れたデスクトップアプリが必要です（`xcrun --find actool` が成功すること） |
| macOS で「確認できません」と出る | Releases の版は署名と公証済みです。自分でビルドした版は未署名なので、一度開こうとしたあと、システム設定 → プライバシーとセキュリティ で **このまま開く** を押してください |
| 起動のたびに復元のダイアログが出る | **Restore** して保存するか、**Discard** してください |

解決しないときは、ブラウザや OS のバージョン、手順、可能なら `.icon` を添えて [Issue](https://github.com/kajisho5/fresnel/issues/new/choose) を立ててください。

## 用語集

| 用語 | 意味 |
|---|---|
| `.icon` | Icon Composer のファイル形式。`icon.json` と `Assets/` を収めたフォルダで、macOS では 1 つのファイルに見える |
| `icon.json` | `.icon` の中の設定ファイル |
| specialization | `icon.json` での外観別・プラットフォーム別の値。fresnel では「バリアント」と呼ぶ |
| Clear／Tinted | システムのモノクロ系の外観。Clear はガラスのような白や黒、Tinted はユーザーが選んだ色で表示する |
| スクワークル | iOS と macOS で使う角丸の四角のマスク |
| フルブリード | 正方形全体を埋める絵。透明な余白や角丸がない |
| `actool` | Xcode に含まれる Apple のアセットカタログコンパイラ |
